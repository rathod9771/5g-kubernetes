Onboarding: register a capability manifest → queue a prebuilt image job → OCI digest verification (no BuildKit required) → Helm/OSM validation → review immutable release → request catalog publication → obtain independent approval → publish to a configured disposable project. Catalog and deployment approval are separate. Initial deployment requires a separate reviewer approval and an enabled disposable target.

Pipeline Jobs and CI/CD Releases show Git capture, build, image digest, registry receipt, package validation and durable failure history. Registry Publications shows exact repository/digest readback evidence.

Deployment approval: separately required; initial deployment requires explicit approval.

Instance update/rollback (P9): request an update/rollback against a WORKLOAD_READY deployment and an already-published release → independent reviewer approval → operator submission (locked, digest/health verified, rollback limited to the immediately prior deployed release) → bounded status observation. Live execution stays blocked until a separately approved disposable OSM v19 test certifies the exact update operation; an unapproved request can be safely cancelled before anything is sent.
